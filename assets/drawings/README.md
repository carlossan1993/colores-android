# Dibujos originales incluidos en la app

Cada dibujo tiene un archivo JSON fuente y un SVG generado. La metadata está en catalog.json; src/content/catalog.ts es un archivo generado.

Para añadir un dibujo, consultar docs/content-standard.md. Ejecutar npm run content:generate y npm run verify en el flujo GitHub antes de enviar el PR. No cambiar IDs ya publicados: el progreso depende de ellos.
